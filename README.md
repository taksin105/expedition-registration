## 3. รายละเอียดจุดบกพร่องที่แอบฝังไว้ 2 จุด (The 2 Hidden Bugs)

### 🐞 Bug #1: ช่องเบอร์โทรศัพท์ยอมให้พิมพ์ตัวอักษรได้โดยไม่แจ้งเตือน
- **ข้อกำหนด (Requirement):** เบอร์โทรศัพท์ต้องเป็นตัวเลข 7 - 15 หลักเท่านั้น
- **จุดที่ผิดในโค้ด (`script.js`):**
  ```javascript
  // โปรแกรมเมอร์ตรวจเฉพาะความยาว แต่ลืมตรวจว่าเป็นตัวเลขหรือไม่!
  const phone = document.getElementById('phone').value.trim();
  if (!phone) {
      setError('phone', 'กรุณากรอกเบอร์โทรศัพท์ติดต่อ');
      isValid = false;
  } else if (phone.length < 7 || phone.length > 15) {
      setError('phone', 'เบอร์โทรศัพท์ต้องมีความยาวระหว่าง 7-15 ตัวอักษร');
      isValid = false;
  }
  ```
- **ขั้นตอนการทดสอบ (Reproduction Steps):**
  1. ไปที่ช่อง "เบอร์โทรศัพท์ (Contact Number)"
  2. พิมพ์ตัวอักษรภาษาอังกฤษหรือภาษาไทย เช่น `abcdefg` หรือ `เบอร์โทรของฉัน`
  3. กรอกช่องอื่นๆ ให้ครบ แล้วกดปุ่ม "ยืนยันการลงทะเบียน (Submit)"
  4. **ผลลัพธ์ที่พบ (Bug):** ระบบอนุญาตให้ผ่านฉลุยและบันทึกข้อมูลสำเร็จ ทั้งที่ไม่ใช่ตัวเลข

---

### 🐞 Bug #2: สามารถส่งฟอร์มสำเร็จได้โดยไม่ต้องติ๊กยอมรับเงื่อนไข
- **ข้อกำหนด (Requirement):** ผู้สมัครต้องคลิกติ๊กถูกที่ช่อง "ฉันได้อ่านและยอมรับข้อตกลงและเงื่อนไข" ก่อนส่งใบสมัครเสมอ หากไม่ติ๊กจะต้องไม่สามารถส่งได้
- **จุดที่ผิดในโค้ด (`script.js`):**
  ```javascript
  // ในฟังก์ชัน Validation โปรแกรมเมอร์ลืมเขียนคำสั่งตรวจสอบ if (!terms.checked)
  // ทำให้ตัวแปร isValid ยังคงมีค่าเป็น true เสมอแม้ผู้ใช้จะไม่ได้ติ๊กยอมรับเงื่อนไข
  ```
- **ขั้นตอนการทดสอบ (Reproduction Steps):**
  1. กรอกข้อมูลทุกช่องให้ถูกต้องครบถ้วน
  2. **เว้นว่างช่อง "ฉันได้อ่านและยอมรับข้อตกลงและเงื่อนไข" ไว้ (ไม่ต้องติ๊กถูก)**
  3. กดปุ่ม "ยืนยันการลงทะเบียน (Submit)"
  4. **ผลลัพธ์ที่พบ (Bug):** ระบบแสดงหน้าต่าง Modal "ลงทะเบียนสำเร็จเรียบร้อย!" ทันที ทั้งที่ไม่ได้ติ๊กยอมรับเงื่อนไข
