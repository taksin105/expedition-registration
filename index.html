1. ข้อมูลส่วนตัวและการติดต่อ (Personal & Contact Information)

ข้อมูลระบุตัวตนและช่องทางที่เจ้าหน้าที่สามารถติดต่อท่านได้โดยตรง

2. ประสบการณ์และตำแหน่งในทีม (Expedition Role & Experience)

ความเชี่ยวชาญทางโบราณคดีและบทบาทหน้าที่ที่ประสงค์จะปฏิบัติงาน

Bug #1 Input Validation / Type Check

ช่องเบอร์โทรศัพท์ (Contact Number) ยอมให้พิมพ์ตัวอักษรได้

ข้อกำหนด (Requirement): ต้องเป็นเบอร์โทรศัพท์ที่เป็นตัวเลขความยาว 7 - 15 หลักเท่านั้น

จุดที่แอบทำ Bug ไว้: ใน script.js โปรแกรมเมอร์ตรวจเช็คเพียงแค่ความยาวตัวอักษร แต่ลืมเขียนโค้ดตรวจสอบว่าเป็นตัวเลขหรือไม่

วิธีทดสอบ (Reproduction Step):

  1. ไปที่ช่องเบอร์โทรศัพท์ พิมพ์ตัวอักษร เช่น abcdefg หรือ เบอร์โทรผม
  2. กรอกช่องอื่นๆ ให้ครบแล้วกดปุ่ม Submit
  3. ผลที่เกิดขึ้น (Bug): ระบบยอมให้ผ่านโดยไม่แจ้ง Error ว่าต้องเป็นตัวเลข
Bug #2 Logic Validation / Required Checkbox

สามารถส่งฟอร์มได้โดยไม่ต้องติ๊กยอมรับเงื่อนไข

ข้อกำหนด (Requirement): ผู้สมัครต้องติ๊กยอมรับเงื่อนไขก่อนส่งฟอร์มเสมอ หากไม่ติ๊กต้องไม่สามารถส่งได้

จุดที่แอบทำ Bug ไว้: ในฟังก์ชันตรวจสอบของ script.js โปรแกรมเมอร์ลืมเขียนคำสั่งตรวจสอบ if (!agreeTerms.checked)

วิธีทดสอบ (Reproduction Step):

  1. กรอกข้อมูลทุกช่องให้ครบถ้วน
  2. เว้นว่างช่อง "ฉันได้อ่านและยอมรับข้อตกลงและเงื่อนไข" ไว้ (ไม่ต้องติ๊กถูก)
  3. กดปุ่ม Submit Registration
  4. ผลที่เกิดขึ้น (Bug): ระบบแสดงหน้าต่างลงทะเบียนสำเร็จทันที ทั้งที่ไม่ได้ติ๊กยอมรับเงื่อนไข
